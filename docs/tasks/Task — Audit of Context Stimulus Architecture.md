Task for GoAn — Audit of Context Stimulus Architecture

Purpose

Проверить, анализировалась ли ранее в документах проекта архитектура контекстных троек стимулов, используемых в тестах:

color (Tst2)

shift (Tst3)

Цель — определить, существует ли уже:

формальное описание пространства контекстных стимулов

анализ их влияния на реакцию

архитектурные ограничения для генерации троек стимулов

RT / ΔV
