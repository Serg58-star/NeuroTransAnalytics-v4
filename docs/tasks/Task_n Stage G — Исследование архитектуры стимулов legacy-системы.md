## Ключевая модель анализа

В проекте используется следующая концептуальная модель:

```
Stimulus
→ Channel activation
→ ΔV components
→ Reaction time
```

Следствие:

**анализ времени реакции без анализа структуры стимулов считается методически некорректным.**

---

# 2. Основной принцип анализа

В системе тестирования существуют **жёсткие ограничения протокола**.

Некоторые параметры **не являются случайными**.

Пример:

```
тест color_red → цвет сигнала всегда красный
```

Поэтому анализ вида:

```
P(color | position)
```

для объединённых тестов **методически некорректен**.

Все расчёты должны выполняться по правилу:

```
анализировать только реально варьирующие параметры протокола
```

---

# 3. Главная цель Stage G

Цель Stage G — понять **структуру стимульной среды legacy-протокола**.

Legacy-система не генерирует независимые стимулы.
Она формирует **динамическую стимульную среду**.

Эта среда влияет на:

```
активацию зрительных каналов
сенсорную адаптацию
готовность реакции
когнитивную нагрузку
```

Задача Stage G — восстановить эту среду и понять её свойства.

# 6. Задача B — Канальная нагрузка контекстных троек

## Цель

Оценить, какую нагрузку на зрительные каналы создаёт контекст.

Каждая тройка переводится в координаты:

```
P = число зелёных
K = число синих
R = число красных
```

---

## Требуется вычислить

распределение:

```
нагрузка P-канала
нагрузка K-канала
нагрузка R-канала
```

по всей последовательности стимулов.

---

## Результаты

1. средняя канальная нагрузка
2. дисперсия канальной нагрузки
3. изменение канальной нагрузки по stimulus_index
