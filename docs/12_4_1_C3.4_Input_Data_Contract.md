# C3.4_Input_Data_Contract.md

---

## 1. General Definition

This document defines the strict input data contract for the NeuroTransAnalytics-v4 system (C3.4 layer).

One Excel file = one test session.

The file must contain only raw and aggregated input data.
No calculations are allowed inside the INPUT layer.

---

## 2. File Structure

* Format: `.xlsx`
* Structure: key-value table

```id="structure"
FIELD | VALUE
```

---

## 3. Excel Sheet Structure

The Excel file must contain two sheets:

### RAW_COPY

Purpose:

* storage of original SZR tables

Rules:

* no modifications
* no calculations
* not used by the system

---

### INPUT

Purpose:

* the only data source for computation

Rules:

* key-value structure
* values only
* no calculations

---

### Invariant

```id="sheet_invariant"
The system reads only the INPUT sheet
```

---

## 4. Meta Fields

```id="meta"
SUBJECT_ID
DATE
TIME
```

### Definitions

**SUBJECT_ID**

* Type: string
* Format: `Familia_IO` (e.g. Ivanov_AM)
* Must match SZR system identifier
* Must remain constant across all sessions

**DATE**

* Type: string
* Format: `dd_mm_yyyy`

**TIME**

* Type: string
* Format: `hh:mm:ss`

## 5. Naming Convention

```id="naming"
<COMPONENT>_<PHASE>_<REGION>_MEAN
```

### COMPONENT

* V1 — simple reaction
* V4 — color processing
* V5 — motion processing
* DV4 — decision time (V4 - V1)
* DV5 — decision time (V5 - V1)

### PHASE

* PRE — before load
* POST — after load

### REGION

* ALL — all stimuli
* LH — left hemisphere
* CENTER — central field
* RH — right hemisphere

## 8. Self-Report (Current State)

All values:

* Type: ordinal
* Scale: Likert 1–7
* Interpretation: intensity (1 = minimal, 7 = maximal)

---

### SELF_SLEEP_QUALITY

Оцените, насколько вы восстановились после сна за последнюю ночь

```id="sleep"
1 — совсем не восстановился, чувствую себя разбитым
2 — очень слабое восстановление
3 — слабое восстановление
4 — среднее, нормальное восстановление (как обычно)
5 — хорошее восстановление
6 — очень хорошее, почти полное
7 — полное восстановление, чувствую себя отдохнувшим и бодрым
```

---

### SELF_APPETITE

Оцените текущий уровень аппетита (желания есть)

```id="appetite"
1 — отсутствует
2 — очень слабый
3 — слабый
4 — средний (обычный)
5 — выше среднего
6 — высокий
7 — очень высокий
```

---

### SELF_ENERGY

Оцените ваш текущий уровень физической энергии (бодрости, сил)

```id="energy"
1 — крайне низкий (чувствую полное истощение)
2 — очень низкий
3 — ниже среднего (сил недостаточно)
4 — средний (обычное состояние)
5 — выше среднего (чувствую достаточный ресурс)
6 — высокий
7 — очень высокий (чувствую прилив сил, готов к нагрузкам)
```

---

### SELF_MOTIVATION

Оцените ваше текущее желание тренироваться

```id="motivation"
1 — отсутствует (совсем не хочу)
2 — очень слабое
3 — слабое
4 — среднее (умеренное желание)
5 — выше среднего (хочу, но не полностью)
6 — сильное
7 — максимальное (очень сильно хочу тренироваться)
```

---

### SELF_MUSCLE_PAIN

Оцените текущий уровень неприятных ощущений в мышцах

```id="pain"
1 — отсутствуют
2 — очень слабые
3 — слабые
4 — умеренные
5 — выше среднего (заметные неприятные ощущения)
6 — сильные
7 — очень сильные (мешают движению)
```

---

### SELF_FOCUS

Оцените, насколько хорошо вам удаётся удерживать концентрацию на технике движения прямо сейчас

```id="focus"
1 — полностью отсутствует (постоянно отвлекаюсь)
2 — очень слабая (крайне трудно сосредоточиться)
3 — слабая (часто отвлекаюсь)
4 — средняя (обычная сосредоточенность)
5 — выше среднего
6 — высокая
7 — максимальная (полностью сосредоточен)
```

## 9. Weekly Dynamics (Self-Report Delta)

All values:

* Type: ordinal
* Range: -3 to +3
* Interpretation: direction and magnitude of change over the last week

---

### Fields

```id="delta_week"
SELF_SLEEP_QUALITY_DELTA_WEEK
SELF_APPETITE_DELTA_WEEK
SELF_ENERGY_DELTA_WEEK
SELF_MOTIVATION_DELTA_WEEK
SELF_MUSCLE_PAIN_DELTA_WEEK
SELF_FOCUS_DELTA_WEEK
```

---

### Question

Как изменилось ваше состояние за последнюю неделю?

---

### Scale

```id="delta_scale"
-3 — значительно ухудшилось
-2 — ухудшилось
-1 — немного ухудшилось
 0 — без изменений
+1 — немного улучшилось
+2 — улучшилось
+3 — значительно улучшилось
```

---

## 10. Invariants

* One file = one session
* System reads only INPUT sheet
* No calculations inside INPUT
* All fields must be present
* No empty values
* Field names must match exactly
* SUBJECT_ID must be consistent across sessions

---

## 11. Validation Rules

* RT values must be numeric
* Self-report (current) must be integers 1–7
* Weekly delta must be integers -3 to +3
* DATE and TIME must match required formats

---

## 12. System Responsibility

* SESSION_ID is generated by the system
* DATETIME is constructed from DATE + TIME
* All calculations occur in C3.4
