# Experiment Mapping in Stimulus Design Space and PSI Architecture of the Legacy System

**Project:** NeuroTransAnalytics v4
**Stage:** G — Stimulus Architecture Research
**Document purpose:** объединённое описание карты экспериментов в пространстве стимулов и архитектуры предстимульных интервалов (PSI) в legacy-системе.

---

# 1. Назначение документа

Данный документ объединяет два взаимосвязанных аспекта архитектуры тестовой системы:

1. **Картирование экспериментов в Stimulus Design Space**
2. **Реальная архитектура PSI (предстимульных интервалов) legacy-системы**

Цели документа:

* определить экспериментальные оси пространства стимулов;
* зафиксировать реальную структуру PSI в legacy-тестировании;
* обеспечить корректную основу для построения **Stimulus Generator v5**;
* избежать методических ошибок при анализе данных.

---

# 2. Пространство стимулов системы

Ранее было установлено, что пространство стимулов может быть представлено как комбинация нескольких ключевых осей:

```text
S = PSI × Channel × Position × Context
```

где:

| ось           | параметр                       |
| ------------- | ------------------------------ |
| Temporal axis | PSI                            |
| Channel axis  | тип канала реакции             |
| Spatial axis  | позиция стимула                |
| Context axis  | структура предшествующих троек |

Это пространство задаёт **экспериментальную архитектуру системы**.

---

# 3. Channel axis — тип канала

Система исследует три типа реакций:

| тест   | канал                 | компонент времени |
| ------ | --------------------- | ----------------- |
| simple | базовый сенсомоторный | ΔV1               |
| color  | парво-канал           | ΔV4               |
| shift  | магно-канал           | ΔV5/MT            |

Таким образом:

```text
Channel = {ΔV1, ΔV4, ΔV5}
```

---

# 4. Spatial axis — позиция стимула

Позиция целевого стимула:

```text
position ∈ {left, center, right}
```

Эта ось используется для исследования:

* латерализации зрительной обработки;
* распределения внимания;
* межполушарных различий реакции.

---

# 5. Context axis — структура предшествующих стимулов

Контекст формируется последовательностью **pre-target троек**.

Возможные типы контекста:

### 5.1 Нейтральный контекст

Сбалансированные комбинации цветов:

```text
ЖЖС
ЖСЖ
ССЖ
```

---

### 5.2 Цветовая адаптация

Контекст с доминирующим цветом.

```text
green-dominant
blue-dominant
```

---

### 5.3 Пространственная адаптация

Контекст с доминирующей позицией.

```text
left-dominant
center-dominant
right-dominant
```

---

### 5.4 Случайный контекст

```text
random triples
```

Контекстная ось является **наименее исследованной частью legacy-системы**, хотя потенциально обладает высокой экспериментальной информативностью.

---

# 6. Temporal axis — PSI

Предстимульный интервал (PSI) является **ключевой временной осью системы**.

PSI определяет:

* состояние сенсомоторной системы;
* уровень готовности реакции;
* степень ожидания стимула.

---

# 7. Как на самом деле устроен PSI в legacy-системе

PSI в системе **не генерируется случайно**.

Он является:

```text
deterministic
predefined
stored in configuration
```

Каждый стимул имеет **заранее заданное значение PSI**.

Пример:

```text
Stimulus 1
PSI = 1600 ms
```

Это означает, что PSI организован как **последовательность**, а не как случайная величина.

---

# 8. Архитектура PSI-последовательности

В тесте используется последовательность PSI:

```text
PSI_sequence = [ψ1, ψ2, ψ3 … ψ36]
```

где:

```text
ψi — фиксированное значение PSI
```

Каждый стимул теста связан с определённым PSI.

Таким образом:

```text
stimulus_index → PSI
```

---

# 9. Реальное пространство PSI

Legacy-система использует **ограниченный набор значений PSI**.

Пример диапазона:

```text
~400–1800 ms
```

Но внутри диапазона используются **конкретные значения**, определённые конфигурацией теста.

Следовательно:

```text
PSI ∈ PSI_config_set
```

где

```text
PSI_config_set = {ψ1, ψ2 … ψn}
```

---

# 10. Методическое следствие архитектуры PSI

Поскольку PSI связан с номером стимула:

```text
stimulus_index → PSI
```

фактически система исследует зависимость:

```text
ΔV = f(PSI_position)
```

а не чистую зависимость:

```text
ΔV = f(PSI_value)
```

Это приводит к потенциальному смешению эффектов:

* адаптации;
* накопления нагрузки;
* обучения;
* предсказуемости стимулов.

---

# 11. Экспериментальная матрица Stimulus Design Space

С учётом реальной архитектуры системы эксперимент можно представить как:

```text
Experiment = PSI_sequence × Channel × Position × Context
```

где:

| параметр     | уровни                           |
| ------------ | -------------------------------- |
| PSI_sequence | фиксированная последовательность |
| Channel      | 3                                |
| Position     | 3                                |
| Context      | несколько типов                  |

---

# 12. Следствие для построения экспериментов

Экспериментальное пространство определяется комбинациями:

```text
PSI_sequence
Channel
Position
Context
```

При этом:

* PSI является **структурным параметром серии**;
* Channel определяет тип реакции;
* Position определяет пространственную ось;
* Context задаёт сенсорный фон.

---

# 13. Ограничения legacy-системы

Legacy-архитектура использует **ограниченное подпространство Stimulus Design Space**.

Ограничения:

```text
target_index = last
PSI = predetermined sequence
context patterns = predefined
```

Это делает систему стабильной, но ограничивает исследовательскую вариативность.

---
