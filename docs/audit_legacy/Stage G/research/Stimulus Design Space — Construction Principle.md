# Stimulus Design Space — Construction Principle

**Project:** NeuroTransAnalytics v4
**Stage:** G — Stimulus Architecture Research
**Document purpose:** формализация принципа построения пространства стимулов системы тестирования СЗР.

---

# 1. Назначение документа

Документ определяет **принцип построения пространства стимулов (Stimulus Design Space)** системы тестирования зрительных реакций.

Цели документа:

* формализовать параметры, определяющие структуру стимулов;
* выделить независимые переменные дизайна теста;
* создать основу для проектирования **Stimulus Generator v5**;
* обеспечить воспроизводимость архитектуры стимулов в аналитических и экспериментальных сценариях.

---

# 2. Принцип параметрического описания стимулов

Стимульная система описывается **не конкретными последовательностями**, а **параметрическим пространством**.

Формально:

```
StimulusSeries = f(P1, P2, …, Pn)
```

где:

```
Pi — независимые параметры дизайна стимулов
```

Таким образом, любой стимул рассматривается как **точка в пространстве параметров**.

---

# 3. Архитектурные уровни пространства стимулов

Stimulus Design Space имеет **трёхуровневую структуру**.

```
Level 1 — Series structure
Level 2 — Triple structure
Level 3 — Circle properties
```

Каждый уровень добавляет новые параметры дизайна.

---

# 4. Level 1 — архитектура серии

Серия является **единицей предъявления стимула**.

Структура:

```
StimulusSeries
    ├── pre-target triples
    └── target triple
```

Реакция регистрируется **на целевую тройку**.

---

## 4.1 Предстимульный интервал (PSI)

```
psi ∈ ℝ+
```

Определяет время между завершением предыдущей реакции и началом новой серии.

Функциональная роль:

* восстановление системы реакции;
* формирование ожидания;
* управление готовностью ответа.

PSI рассматривается как **ключевая исследовательская ось системы**.

---

## 4.2 Длина серии

```
series_length
```

Количество троек, предъявляемых до целевой тройки.

В legacy-системе используется диапазон:

```
4–7 троек
```

---

## 4.3 Последовательность троек

```
triple_sequence = [T1, T2, …, Tn]
```

Определяет визуальный поток стимулов перед целевой тройкой.

---

## 4.4 Позиция целевой тройки

```
target_index
```

Позиция тройки, на которую должна быть выполнена реакция.

В legacy-системе:

```
target_index = last
```

---

# 5. Level 2 — архитектура тройки

Каждая тройка содержит **три одновременно предъявляемых стимула**.

Структура:

```
TripleFrame
    left_circle
    center_circle
    right_circle
```

---

## 5.1 Цветовая конфигурация тройки

```
triple_colors = (c_left, c_center, c_right)
```

где:

```
c ∈ {red, green, blue}
```

---

## 5.2 Тип тройки

```
triple_type ∈ {pre-target, target}
```

---

## 5.3 Динамическое свойство

```
movement ∈ {none, shift_left, shift_center, shift_right}
```

В legacy-системе движение появляется **только в target-тройке shift-теста**.

---

# 6. Level 3 — свойства круга

Каждый круг обладает набором параметров.

---

## 6.1 Цвет круга

```
color ∈ {red, green, blue}
```

Функциональная связь с каналами:

```
red → Parvocellular pathway
motion → Magnocellular pathway
```

---

## 6.2 Пространственная позиция

```
position ∈ {left, center, right}
```

Позиция является не только геометрическим параметром, но и фактором:

* латерализации реакции;
* распределения внимания по полям зрения.

---

## 6.3 Движение круга

```
motion ∈ {none, shift}
```

Для shift-теста используется движение:

```
circle → midline → back
```

---

## 6.4 Амплитуда сдвига

```
shift_amplitude
```

В legacy-системе фиксирована.

---

## 6.5 Временной профиль тройки

Каждая тройка отображается в течение фиксированного интервала:

```
frame_duration = ROTATE_PERIOD
```

---

# 7. Полное пространство стимулов

Полный вектор параметров стимульной серии:

```
StimulusSeries =
(
psi,
series_length,
triple_sequence,
target_index,
triple_colors,
triple_type,
movement,
color,
position,
motion,
shift_amplitude,
frame_duration
)
```

Этот набор параметров образует **Stimulus Design Space системы**.

---

# 8. Независимые и зависимые параметры

### Независимые параметры

```
psi
series_length
triple_sequence
target_index
target_position
target_color
target_motion
```

### Зависимые параметры

```
movement
shift_amplitude
frame_duration
```

---

# 9. Реальное пространство стимулов legacy-системы

Legacy-система использует ограниченное подпространство общего пространства стимулов.

Фиксированы:

```
target_index = last
shift_amplitude = fixed
frame_duration = fixed
```

Основная вариативность определяется параметрами:

```
psi
target_position
target_color
pre-target sequence
```

---

# 10. Геометрия пространства стимулов

Пространство стимулов можно представить как декартово произведение трёх слоев:

```
S = PSI × Target × Context
```

где

```
PSI — временной слой
Target — параметры целевого стимула
Context — предшествующие тройки
```

---

# 11. Архитектурные слои стимульной системы

Stimulus Design Space состоит из трех независимых информационных слоев:

```
1. Context layer
2. Target layer
3. Temporal layer
```

---

### Context layer

```
pre-target triples
```

Формируют сенсорный фон и предотвращают предсказуемость стимулов.

---

### Target layer

```
target_position
target_color
target_motion
```

Определяют активацию зрительных каналов.

---

### Temporal layer

```
psi
frame_duration
```

Определяют состояние системы реакции.

---

# 12. Значение модели

Представление стимулов как пространства параметров позволяет перейти от фиксированных последовательностей к **генерации стимулов через параметрическое пространство**.

Формально:

```
StimulusGenerator
    sample(S)
```

где

```
S — Stimulus Design Space
```
