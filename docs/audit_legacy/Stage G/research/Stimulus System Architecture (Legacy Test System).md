# Stimulus System Architecture (Legacy Test System)

**Project:** NeuroTransAnalytics v4
**Stage:** G — Stimulus Architecture Research
**Document purpose:** формальная реконструкция архитектуры стимульной системы legacy-тестирования.

---

# 1. Назначение документа

Документ фиксирует **формальную модель стимульной системы**, использовавшейся в legacy-комплексе тестирования скоростей зрительных реакций (СЗР).

Цели документа:

* реконструировать архитектуру предъявления стимулов;
* определить единицу стимульной информации;
* подготовить формальную основу для разработки **Stimulus Generator v5**;
* исключить потерю архитектурных знаний при переходе между аналитическими чатами.

---

# 2. Общая архитектура стимульной системы

В системе используются **два принципиально разных режима предъявления стимулов**.

| режим                    | тесты            |
| ------------------------ | ---------------- |
| **Single Stimulus Mode** | simple           |
| **Triple Series Mode**   | color_red, shift |

---

# 3. Single Stimulus Mode (simple-тест)

В simple-тесте предъявляется **одиночный стимул**.

Структура стимула:

```
Stimulus
    position ∈ {left, center, right}
    color ∈ {red, green, blue}
    psi
```

Особенности:

* на экране находится **один круг**;
* позиция стимула фиксирована;
* каждый стимул является **независимым событием**.

Функциональная роль теста:

```
Stimulus → ΔV1 → RT
```

Тест используется для оценки **базовой сенсомоторной компоненты реакции (ΔV1)**.

---

# 4. Triple Series Mode (color_red и shift)

В двух других тестах используется **серийная архитектура стимулов**.

Структура:

```
StimulusSeries
    ├── pre-target triples
    └── target triple
```

Реакция регистрируется **только на последнюю тройку серии**.

---

# 5. Структура тройки стимулов

Каждая тройка состоит из **трех кругов**, расположенных одновременно на экране.

```
TripleFrame
    left_circle
    center_circle
    right_circle
```

Цвета кодируются:

| обозначение | цвет  |
| ----------- | ----- |
| Ж           | green |
| С           | blue  |
| К           | red   |

Пример тройки:

```
ЖЖС
```

означает:

```
left = green
center = green
right = blue
```

---

# 6. Архитектура color_red-теста

Серия состоит из:

```
pre-target triples
target triple
```

## 6.1 Pre-target тройки

Перед целевой тройкой отображаются **несколько комбинаций троек**, содержащих только:

```
green
blue
```

Пример:

```
ЖЖС
ЖСЖ
ССЖ
```

Функции pre-target серии:

* устранение предсказуемости стимула;
* адаптация зрительных каналов;
* стабилизация внимания.

---

## 6.2 Target-тройка

В последней тройке появляется **красный круг**.

Возможные позиции:

```
left
center
right
```

Пример:

```
ЖСК
```

где

```
right = red (target)
```

Задача испытуемого — реагировать на **появление красного круга**.

Функциональная роль теста:

```
StimulusSeries → Parvocellular channel → ΔV4 → RT
```

---

# 7. Архитектура shift-теста

Структура серии аналогична:

```
StimulusSeries
    ├── pre-target triples
    └── target triple
```

## 7.1 Pre-target тройки

Перед целевой тройкой отображаются комбинации троек **трех цветов**, но:

```
movement = none
```

---

## 7.2 Target-тройка

В последней тройке:

* один из кругов выполняет **сдвиг**;
* движение выполняется к центральной линии и обратно.

Параметры:

```
movement duration ≈ 150 ms
```

В конфигурации указывается:

* цвет круга
* позиция круга
* тип движения

Функциональная роль теста:

```
StimulusSeries → Magnocellular channel → ΔV5/MT → RT
```

---

# 8. Реальная единица стимула

Ключевой вывод реконструкции:

в triple-режиме **стимулом является не круг**, а **серия троек**.

```
Stimulus = StimulusSeries
```

а реакция относится к:

```
TargetTriple
```

---

# 9. Формальная модель StimulusSeries

```
StimulusSeries
    psi
    sequence_length
    triple_sequence
    target_triple_index
```

Каждая тройка:

```
TripleFrame
    left_color
    center_color
    right_color
    movement
```

где

```
movement ∈ {none, left_shift, center_shift, right_shift}
```

---

# 10. Значение реконструкции для Stage G

Полученная модель является **основой для проектирования генератора стимулов**.

Stimulus Generator должен уметь создавать:

```
StimulusSeries
    psi
    pre_target_patterns
    target_pattern
```

где target_pattern определяет:

```
target_position
target_color
target_motion
```

---

# 11. Ключевой архитектурный вывод

Legacy-система построена вокруг **серийной структуры стимулов**, а не вокруг отдельных стимулов.

Поэтому:

```
Stimulus → Channel activation → ΔV component → RT
```

должно интерпретироваться как

```
StimulusSeries → Channel activation → ΔV component → RT
```
