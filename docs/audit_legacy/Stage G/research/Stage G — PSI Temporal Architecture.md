# 1. Назначение документа

Документ фиксирует **полную архитектуру Pre-Stimulus Interval (PSI)** в системе тестирования СЗР и её значение для проектирования **Stimulus Generator v5**.

Документ объединяет:

* реконструкцию PSI legacy-протокола
* результаты анализа Stage L
* интерпретацию влияния PSI на компонентные задержки
* требования к генерации PSI в v5

Документ является **каноническим описанием PSI**. После его фиксации повторный анализ PSI в будущих чатах проекта не требуется.

---

# 2. PSI в архитектуре теста

В legacy-системе PSI является **детерминированной частью экспериментального протокола**.

Каждый стимул имеет фиксированный предстимульный интервал:

```
stimulus_index → PSI
```

Каждый тест содержит:

```
36 stimulus events
```

Всего:

```
3 tests × 36 stimuli = 108 stimulus events
```

PSI одинаков для всех испытуемых и воспроизводится идентично во всех сессиях.

---

# 3. Реальный диапазон PSI

По данным `codebook_for_SZR.xlsx`:

```
PSI_min = 800 ms
PSI_max = 2800 ms
```

Для тестов **color** и **shift** используется дискретный набор:

```
800
1200
1600
2000
2400
2800
```

Формально:

```
PSI = 800 + 400k
k ∈ {0..5}
```

Дискретность связана с периодом смены троек стимулов:

```
ROTATE_PERIOD = 400 ms
```

PSI определяет количество троек стимулов перед целевым событием.

---

# 4. Особенности PSI в разных тестах

## Tst1 — simple reaction

PSI распределён псевдослучайно:

```
≈ 920–2300 ms
```

Особенности:

* значения не кратны 400
* интервалы нерегулярны
* отсутствует дискретная сетка

Цель:

```
исключить предсказуемость момента стимула
```

---

## Tst2 — color reaction

Используется дискретная сетка:

```
800–2800 ms
шаг 400 ms
```

PSI определяет количество предварительных троек цветовых стимулов.

---

## Tst3 — shift reaction

Используется тот же набор:

```
800–2800 ms
шаг 400 ms
```

но порядок PSI отличается от color-теста, что снижает вероятность адаптации испытуемых.

---

# 5. PSI как глобальная временная ось

Поскольку PSI:

* фиксирован
* повторяется во всех сессиях
* распределён по всему протоколу

он формирует **глобальную временную координату эксперимента**.

```
temporal_context = f(PSI)
```

PSI является:

```
global temporal modulation factor
```

---

# 6. PSI как естественный экспериментальный градиент

Диапазон 800–2800 ms создаёт градиент состояния готовности реакции.

Это позволяет анализировать зависимости:

```
RT ~ PSI
```

После перехода к компонентной модели:

```
ΔV4 ~ PSI
ΔV5 ~ PSI
```

Таким образом legacy-протокол содержит встроенный эксперимент по **временной динамике готовности системы**.

# 7. Эмпирические результаты Stage L

Анализ медианных компонент показал:

```
ΔV4(PSI)
ΔV5(PSI)
```

Форма зависимости:

```
PSI ↑ → latency ↓ → minimum → latency ↑
```

Это U-образная кривая.

# 8. Оптимальное окно временной готовности

Stage L определил:

```
PSI ∈ (2000, 2400] ms
```

Минимальные медианные задержки:

| component | minimal median Δ |
| --------- | ---------------- |
| ΔV4       | 88 ms            |
| ΔV5/MT    | 118 ms           |

Это соответствует максимальной сенсомоторной готовности системы.

# 9. Возможная модель влияния PSI

Форма зависимости объясняется двумя процессами.

### восстановление сенсомоторной готовности

После реакции происходит временное снижение готовности.

```
recovery_state = f(PSI)
```

### модуляция внимания

При слишком длинных PSI наблюдается снижение устойчивости внимания.

```
attention drift
```

Итоговая модель:

```
latency(PSI) =
recovery_component
+
attention_component
```

Наблюдается небольшое смещение минимумов:

```

dorsal pathway (MT/V5)
```

# 11. Связь PSI и stimulus_index

Stage L выявил две независимые временные оси.

### stimulus_index

отвечает за:

```
progressive cognitive load
fatigue accumulation
```

### PSI

отвечает за:

```
intratrial readiness
anticipation state
```

Совместный эффект:

```
Δ = base_load(stimulus_index)
  + readiness_modulation(PSI)
```

# 12. Лаг-корреляции

Обнаружена слабая корреляция:

```
Δ(t) ~ PSI(t−1)
ρ ≈ 0.08–0.09
```

Этот эффект объясняет менее:

```
1 % вариации
```

Причина — структура PSI-последовательности.

Поскольку PSI изменяется плавно:

```
PSI(t) ↔ PSI(t−1)
```

возникает вторичная корреляция:

```
Δ(t) ↔ PSI(t−1)
```

Этот эффект **не является доказательством обучения испытуемых**.

---

# 13. Спектральный анализ PSI

FFT-анализ последовательности PSI показал:

* отсутствие выраженных спектральных пиков
* отсутствие доминирующих периодов

Последовательность является:

```
quasi-random deterministic sequence
```

без скрытых ритмов.

---

# 14. Связь PSI и циклов внимания

Stage L обнаружил автокорреляции:

```
lag-1 ≈ 0.29–0.35
lag-2 ≈ 0.33–0.39
```

FFT показывает, что эти циклы **не порождаются PSI напрямую**.

Вероятная причина:

```
internal attention dynamics
+
task structure
```

# 15. Требования к PSI в Stimulus Generator v5

В v5 необходимо поддерживать **два режима работы PSI**.

### legacy-режим

Используются **оригинальные последовательности PSI legacy-протокола**.

Цель:

```
полная сопоставимость с legacy-данными
```

---

### generated-режим

Последовательности PSI генерируются автоматически, но должны сохранять свойства legacy-системы:

```
PSI range: 800–2800 ms
PSI discrete levels
quasi-random ordering
absence of long monotonic runs
```

Этот режим позволяет:

```
разрушить адаптацию к фиксированной последовательности
```

и расширить исследовательские возможности.

---

# 16. Обязательная запись PSI в базе данных

В v5 **каждое стимульное событие должно хранить PSI**.

Минимальная структура записи:

```
session_id
test_type
stimulus_index
psi
color
position
context
```

Это необходимо для анализа:

```
ΔV ~ PSI
```

и сравнения результатов с legacy-данными.

