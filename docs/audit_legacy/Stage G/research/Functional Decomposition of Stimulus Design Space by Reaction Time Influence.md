# Functional Decomposition of Stimulus Design Space by Reaction Time Influence

**Project:** NeuroTransAnalytics v4
**Stage:** G — Stimulus Architecture Research
**Document purpose:** определить, какие параметры пространства стимулов реально влияют на время реакции, а какие оказывают минимальное влияние.

---

# 1. Назначение документа

Настоящий документ выполняет **функциональную декомпозицию Stimulus Design Space** по степени влияния параметров на время реакции.

Цели документа:

* определить параметры, которые действительно управляют временем реакции;
* отделить функционально значимые параметры от структурных;
* выделить минимальный набор параметров для проектирования **Stimulus Generator v5**;
* подготовить основу для экспериментального картирования пространства стимулов.

---

# 2. Формальная постановка задачи

Stimulus Design Space был ранее определён как параметрическое пространство:

```text
StimulusSeries = f(P1, P2, …, Pn)
```

Время реакции рассматривается как функция этого пространства:

```text
RT = f(S)
```

где:

```text
S — Stimulus Design Space
```

Задача данного документа — определить, какие параметры пространства **действительно входят в эту функцию**.

---

# 3. Классы влияния параметров

Параметры пространства стимулов делятся на четыре функциональных класса.

| класс                 | характеристика                       |
| --------------------- | ------------------------------------ |
| Primary drivers       | напрямую определяют время реакции    |
| Secondary modulators  | изменяют время реакции умеренно      |
| State regulators      | регулируют состояние системы реакции |
| Structural parameters | почти не влияют на время реакции     |

---

# 4. Primary drivers (основные управляющие параметры)

Эти параметры определяют **центральную компоненту реакции**.

---

## 4.1 Тип целевого сигнала

```text
target_property
```

Возможные варианты:

```text
color detection
motion detection
```

Функционально это означает выбор зрительного канала:

```text
Parvocellular pathway
Magnocellular pathway
```

Тип целевого сигнала определяет центральную компоненту реакции:

```text
ΔV4
или
ΔV5/MT
```

Это **наиболее сильный фактор**, влияющий на время реакции.

---

## 4.2 Позиция целевого сигнала

```text
target_position ∈ {left, center, right}
```

Позиция влияет на:

* распределение внимания;
* латерализацию обработки;
* время переключения внимания.

Типичный диапазон влияния:

```text
10–40 ms
```

---

## 4.3 Предстимульный интервал (PSI)

```text
psi
```

PSI управляет:

* восстановлением сенсомоторной системы;
* готовностью реакции;
* состоянием ожидания.

Типичная зависимость времени реакции от PSI:

```text
RT = a + b * exp(-psi / τ)
```

То есть:

* короткий PSI → увеличение RT;
* длинный PSI → достижение плато.

PSI является **одной из ключевых исследовательских осей системы**.

---

# 5. Secondary modulators (вторичные модуляторы)

Эти параметры влияют на время реакции через **модуляцию сенсорного контекста**.

---

## 5.1 Цветовой контекст

```text
pre-target color sequence
```

Цветовой контекст влияет через механизмы:

```text
chromatic adaptation
```

Например:

если перед красным стимулом длительно предъявляются зелёные стимулы, реакция на красный сигнал может ускоряться.

Типичный диапазон влияния:

```text
5–20 ms
```

---

## 5.2 Пространственный контекст

```text
pre-target position sequence
```

Если целевой стимул появляется в той же позиции, что и предыдущие стимулы:

```text
RT уменьшается
```

Если позиция неожиданная:

```text
RT увеличивается
```

Типичный диапазон влияния:

```text
10–30 ms
```

---

## 5.3 Длина серии

```text
series_length
```

Влияет через:

* сенсорную адаптацию;
* устойчивость внимания.

Однако влияние относительно слабое.

---

# 6. State regulators (регуляторы состояния системы)

Эти параметры не кодируют стимульную информацию, но влияют на **состояние системы реакции**.

---

## 6.1 Темп предъявления троек

```text
frame_duration
```

Если ритм предъявления стимулов регулярный, формируется:

```text
temporal prediction
```

Это может ускорять реакцию.

---

## 6.2 Предсказуемость целевой тройки

```text
target_index
```

Если целевая тройка всегда находится в фиксированной позиции серии (например, всегда последняя), испытуемый может предсказывать её появление.

Это снижает время реакции за счёт механизма:

```text
anticipatory timing
```

---

# 7. Structural parameters (структурные параметры)

Эти параметры почти не влияют на время реакции.

---

## 7.1 Конкретные комбинации троек

Например:

```text
ЖЖС
ЖСЖ
ССЖ
```

Если сохраняется баланс:

* цветов,
* позиций,

конкретный порядок троек практически не влияет на время реакции.

---

## 7.2 Амплитуда сдвига

```text
shift_amplitude
```

Если движение достаточно заметно для восприятия, дальнейшее увеличение амплитуды почти не влияет на время реакции.

---

# 8. Карта влияния параметров

| параметр            | влияние       |
| ------------------- | ------------- |
| target_property     | очень сильное |
| psi                 | очень сильное |
| target_position     | сильное       |
| pre-target color    | умеренное     |
| pre-target position | умеренное     |
| series_length       | слабое        |
| frame_duration      | слабое        |
| triple_sequence     | минимальное   |
| shift_amplitude     | минимальное   |

---

# 9. Минимальное функциональное пространство стимулов

Анализ показывает, что из полного Stimulus Design Space реально значимы только пять параметров:

```text
psi
target_property
target_position
context_color
context_position
```

Остальные параметры выполняют **структурную или вспомогательную роль**.

---

# 10. Минимальная модель времени реакции

В первом приближении время реакции может быть описано как функция пяти переменных:

```text
RT = f(
    psi,
    target_property,
    target_position,
    context_color,
    context_position
)
```

---

# 11. Следствие для Stimulus Generator v5

Stimulus Generator должен управлять прежде всего **ключевыми осями пространства стимулов**, а не всеми параметрами конструкции стимулов.

Минимальная архитектура генератора:

```text
StimulusGenerator
    psi_distribution
    target_channel
    spatial_axis
    context_pattern
```
