# Stage H — Load Index Computation

## Статус
Инвариант (зафиксировано для реализации)

---

## 1. Δ внутри сессии

### Инвариант 1
Для любой переменной `X`:

ΔX = X_POST − X_PRE

---

## 2. Нормализация

### Инвариант 2
Используется относительное изменение:

ΔX_norm = (X_POST − X_PRE) / X_PRE

### Ограничения
- применяется только при X_PRE ≠ 0  
- при X_PRE = 0 → переменная исключается из расчёта

---

## 3. Направление влияния (S)

### Инвариант 3 — объективные компоненты

Рост = ухудшение → S = +1

- V1 = +1  
- V4 = +1  
- V5 = +1  
- DV4 = +1  
- DV5 = +1  

---

### Инвариант 4 — субъективные шкалы

Рост = улучшение → S = -1  
Рост = ухудшение → S = +1  

- SELF_SLEEP_QUALITY = -1  
- SELF_APPETITE = -1  
- SELF_ENERGY = -1  
- SELF_MOTIVATION = -1  
- SELF_FOCUS = -1  
- SELF_MUSCLE_PAIN = +1  

---

## 4. Приведённое изменение

### Инвариант 5

Z_X = S_X * ΔX_norm

### Интерпретация
- Z_X > 0 → увеличение нагрузки  
- Z_X < 0 → улучшение  

---

## 5. Структура индекса

### 5.1. Объективный блок

Z_obj = (Z_V1 + Z_V4 + Z_V5 + Z_DV4 + Z_DV5) / 5

---

### 5.2. Субъективный блок

Z_subj = (
    Z_SLEEP +
    Z_APPETITE +
    Z_ENERGY +
    Z_MOTIVATION +
    Z_PAIN +
    Z_FOCUS
) / 6

---

### 5.3. Итоговый индекс

### Инвариант 6

LoadIndex = (Z_obj + Z_subj) / 2

---

## 6. Используемые переменные

### Инвариант 7

### Объективные:
- V1  
- V4  
- V5  
- DV4  
- DV5  

### Субъективные:
- SELF_SLEEP_QUALITY  
- SELF_APPETITE  
- SELF_ENERGY  
- SELF_MOTIVATION  
- SELF_MUSCLE_PAIN  
- SELF_FOCUS  

---

## 7. Интерпретация

### Инвариант 8

- LoadIndex > 0 → рост нагрузки  
- LoadIndex ≈ 0 → стабильное состояние  
- LoadIndex < 0 → восстановление / улучшение  

---

## 8. Свойства модели

### Инвариант 9

LoadIndex — это:

безразмерная относительная мера изменения состояния системы  
в пределах одной сессии (PRE → POST)

---

## 9. Ограничения модели

- используется только C3.4 Input Data Contract  
- отсутствуют внешние нормативы  
- не используются показатели вариативности  
- отсутствуют веса  
- отсутствует параметризация  

---

## 10. Готовность к реализации

Модель:
- полностью детерминирована  
- не требует настройки  
- реализуется напрямую в C3.4 pipeline  
- совместима с архитектурой ΔV-компонент
